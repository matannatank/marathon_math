# אתר מתן כחלון - מרתונים ושיעורים פרטיים במתמטיקה

מאגר העבודה של האתר: האפיון, ההדמיה, ובהמשך הקוד עצמו.

## מה יש כאן

| קובץ / תיקייה | מה זה |
|---|---|
| `spec.md` | האפיון המלא (גרסה 5, סופית למפתח). מקור האמת לכל החלטה על האתר |
| `mockup/` | הדמיה של כל העמודים, בגודל מסך נייד. קובצי HTML עצמאיים שנפתחים בדפדפן |

## סדר קריאה מומלץ

1. `spec.md` - התקציר, "מבנה האתר" ו"עמוד קורס".
2. `mockup/home.html` - ומשם אפשר לנווט בין העמודים.
3. ב-`spec.md`: "הרשמה, תשלום וגישה לתכנים", "דרישות טכניות ותחזוקה" ו"נושאים פתוחים".

## עמודי ההדמיה

| קובץ | עמוד |
|---|---|
| `mockup/home.html` | עמוד הבית |
| `mockup/course-linear-algebra.html` | עמוד קורס - אלגברה לינארית |
| `mockup/course-calculus.html` | עמוד קורס - חדו"א |
| `mockup/course-probability.html` | עמוד קורס - הסתברות |
| `mockup/thanks.html` | עמוד תודה (מרתון חי) |
| `mockup/private-lessons.html` | שיעורים פרטיים |
| `mockup/terms.html` | תקנון ואחריות מעבר |

ההדמיה מראה מבנה, סדר מקטעים וצבעים. היא לא הקוד של האתר: טקסט בסוגריים מרובעים הוא מקום שמור לתוכן שעוד חסר (תמונות, תאריכים, מספרי קורס).

## כללי עבודה

- כל שינוי בהחלטות נכנס קודם ל-`spec.md`, ורק אחר כך לקוד.
- כל תוכן שמתן אמור לעדכן לבד (מחירים, תאריכים, טקסטים, קישורים) נשמר בקובצי תוכן נפרדים מהקוד, כמפורט בפרק "דרישות טכניות ותחזוקה".
